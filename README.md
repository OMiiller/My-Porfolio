# Portfólio — João Gabriel Miiller

Site estático de apresentação pessoal e portfólio de desenvolvimento de software.

## Visualizar localmente

Abra `index.html` no navegador. Para publicar, mantenha a pasta `assets` junto ao arquivo.

## Arquivos principais

- `index.html`: conteúdo, estilos e interações do site.
- `assets/ambiente-inspiracao.mp4`: vídeo exibido na abertura.
- `assets/joao-gabriel.jpeg`: foto de perfil.
- `assets/fonts/blastimo-sans.ttf`: fonte usada no nome da seção “Quem sou”.
